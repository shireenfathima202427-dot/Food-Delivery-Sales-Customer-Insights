# PYTHON FOR DATA ANALYTICS

# 🍔 Food Delivery Sales & Customer Insights

## 📌 Project Overview

This project analyzes food delivery order data to uncover customer ordering patterns, restaurant performance, revenue trends, and delivery insights.

Using Python, Pandas, Matplotlib, and Seaborn, the dataset was cleaned, analyzed, and visualized to generate meaningful business insights.

---

## 🎯 Objectives

* Analyze customer ordering behavior
* Identify peak ordering hours
* Discover top-performing restaurants
* Measure revenue performance
* Evaluate delivery trends
* Generate business insights through data visualization

---

## 🛠 Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook
* Git & GitHub

---

## 🧹 Data Cleaning

* Removed duplicate records
* Handled missing values
* Converted date and time columns
* Created Hour, Day, and Month features
* Validated data consistency

---

## 📊 Visualizations

* Peak Order Hours Analysis
* Order Status Distribution
* Top Restaurants by Orders
* Top Restaurants by Revenue
* Top Cities by Orders
* Customer Rating Distribution
* Rating vs Revenue Analysis
* Delivery Distance Analysis
* Top Customers by Orders
* Correlation Heatmap
* Interactive Dashboard

---

## 🔍 Key Insights

* Peak order activity occurs during specific hours.
* A small group of restaurants generates most revenue.
* Customer ratings influence restaurant performance.
* Delivery distance impacts operational efficiency.
* Repeat customers contribute significantly to orders.
